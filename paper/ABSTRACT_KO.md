# 초록 (한국어)

희소 CNN 가속기에서 보고되는 속도 향상은 비교 대상의 연산 자원이 서로 다를 때 의미를 잃는다.
본 연구는 곱셈기 예산을 고정한 조건에서 그 곱셈기를 **어느 병렬 축에 투입할 것인가**를
측정으로 비교한다.

양자화 VGG11의 합성곱 계층(K=576, COUT=128)을 대상으로 창 단위 MAC 연산기를 SystemVerilog로
구현하고, 0인 입력의 곱셈을 생략하는 희소 연산을 기준으로 출력 채널 병렬도 P를 키우는 구조와
비영 tap을 T개 뱅크로 분배하는 구조를 같은 곱셈기 수에서 비교하였다. 정수 참조 모델과 독립
구현한 cycle 모델을 함께 사용해 167개 시험 설정에서 출력 3,447,344개의 불일치가 없음을
확인하였다.

곱셈기 64개 기준에서 두 구조의 창당 처리 cycle 차이는 5.1%에 그쳤다. 반면 곱셈기 하나를
추가하는 비용은 P축이 LUT 138.5개·플립플롭 111.6개인 데 비해 T축은 89.8개·43.8개로 각각 35%,
61% 낮았다. 분산 RAM은 DSP를 사용하지 않는 모든 구성에서 두 구조 모두 레인당 22개로 나타나,
출력 데이터패스가 P×T가 아니라 P에 의해 결정됨을 보였다.

Zynq-7020(XC7Z020-CLG484) 보드에서 1,024개 입력 창을 처리한 결과 출력 131,072개가 모두
참조값과 일치하였고, 총 처리 cycle은 시뮬레이션 예측값과 정확히 동일하였다. 하드웨어에 내장한
입출력 대기 cycle 카운터가 모두 0이므로 이 수치는 메모리 경로가 아닌 코어 자체의 성능이다.

곱셈기 예산이 고정되고 출력 채널 병렬도가 면적을 좌우하는 설계에서는, 뱅크 분배가 동일한
처리량을 더 작은 면적으로 달성한다.

**주제어** — 희소 합성곱 가속기, FPGA, 등가 자원 비교, 설계공간 탐색, 하드웨어 검증
